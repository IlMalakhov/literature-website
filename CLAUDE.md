# dasha-website

Одностраничник репетитора по литературе. React 19 + Vite + vite-react-ssg, GSAP/ScrollTrigger, Lenis.

## Визуальная проверка — читать до первого скриншота

**Скриншоты Browser-панели в этом проекте не работают.** Компositor виснет после
любого релоада или скролла и отдаёт сплошной чёрный кадр до конца сессии.
Resize не спасает — это проверено много раз, не трать на это вызовы.

Порядок действий:

1. **По умолчанию доказывай без пикселей** — DOM и computed styles через
   `javascript_tool`, плюс `dist/index.html` после сборки (SSG рендерит страницу
   в статический HTML, там видно всё, что отрендерилось).
2. **Нужны пиксели — `bun run shot`**, не панель:
   ```
   bun run shot                          # вьюпорт, верх страницы
   bun run shot -- '#results'            # секция посреди страницы, без скролла
   bun run shot -- '#road' --motion      # с анимациями (по умолчанию reduced-motion)
   bun run shot -- '#composer' --hover '.tgc__send'   # состояние :hover
   ```
   Флаги: `--url` (по умолчанию :4600), `--width`, `--height`, `--out`, `--full`,
   `--hover`. Скрипт поднимает свой headless Chrome по CDP, панель ему не мешает.
   `--hover` включает `:hover` на одном элементе через `CSS.forcePseudoState` —
   мыши в headless нет, поэтому иначе ховер не снять. Селектор клипа и селектор
   ховера независимы: клип — что попадёт в кадр, `--hover` — что подсвечено.
   Вложенные правила (`.ticket:hover .ticket__stub svg`) применяются тоже.
3. Клип задаётся в координатах документа, поэтому **скроллить не нужно и вредно**:
   попытки подтянуть элемент вверх через `marginTop`/`display:none` наезжают на
   соседние блоки и рисуют баги, которых нет.

Панель годится для DOM-инструментов (`read_page`, `javascript_tool`,
`read_console_messages`) — они работают нормально. Не годится только капча кадра.

## CSS

`src/styles.css` — только точка входа со списком `@import`. Сами стили в
`src/styles/`, 26 файлов. **Числовой префикс = порядок каскада**: `00`–`05` это
фундамент (шрифты, токены, reset, типографика, сетка, фиксированный хром), `06`–`25`
компоненты. Переставлять импорты нельзя.

Правка компонента идёт в его файл. Новая секция — `26-*.css` в конец.
Общие на несколько компонентов: `03-typography`, `07-buttons`, `23-reveal`.
